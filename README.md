# Lucky Morning · 幸运早练课堂工具台

20 分钟跨学科早练课（英语 × 数学 × 财商）的课堂工具网页，替代纸条抽签杯与黑板计分：

- **游戏 A · 幸运字母**：抽 7 个字母球开奖 + 单词遮罩/揭晓，题库 46 词按三档难度分组
- **游戏 B · 开奖**：数字滚动开奖 + 三张卡自动判定
- **计分板**：分组快捷加分、开局基金、撤销、自动保存
- **规则速查**：奖级表 / 三卡规则 / 组票票样

## 使用

直接打开网页即可，无需安装、无外网依赖（可离线使用）：

```
https://<你的GitHub用户名>.github.io/lucky-morning/
```

- 教师面板（默认折叠）里选词或自定义单词；`空格` 键 = 抽字母 / 开奖
- 右上角可开音效与全屏，适合投影

## 说明

单文件静态页面（`index.html`），纯前端实现。仅供课堂教学演示概率概念使用；课堂积分下课清零，未成年人不得购买彩票。
